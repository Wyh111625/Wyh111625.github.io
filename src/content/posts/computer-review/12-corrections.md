> 本文属于「计算机复习」系列。[系列目录与阅读说明](/posts/computer-review/00-overview/)；文中页码指原教材 PDF 页码，Windows／Office 操作沿用 Windows 7／Office 2010 语境。

下列列出影响记忆和解题的主要问题，避免把 OCR 结果或原书答案机械背下来。“原页核对”表示已回看扫描图片；“条件／版本修正”强调适用范围。

| 原书位置 | 问题 | 应掌握的结论 |
|---|---|---|
| p.14 进制大小题，原页核对 | 答案给 DH 最大 | 15D=15，1110B=14，16O=14，DH=13；应选 15D |
| p.14 与／或题，原页核对 | 文字与 ∧/∨ 对应颠倒，且有重复选项 | 与用 ∧，或用 ∨；1100110 AND 1000111=1000110，OR=1100111 |
| p.19 点阵题 | “144KB”未统一二进制换算口径 | 准确原始值 144000B，等于 140.625KiB |
| p.22 EDSAC | “最早存储程序计算机”缺少历史限定 | 区分 Manchester Baby 实验机与 EDSAC 实用机 |
| p.25 程序计数器题 | 题解字母与部件含义不一致 | 下一条指令地址考 PC，不能选 Cache |
| p.26 ROM 表，原页核对 | ROM 写成断电丢失 | ROM 非易失；RAM、常规 Cache 易失 |
| p.24、33、49 CPU 性能 | 主频越高必然越快、整机只由 CPU 决定 | 同条件可比较主频；跨架构和实际系统看综合性能 |
| p.41—42 | 操作数解释、编译与解释、4GL 分类混乱 | 操作码给功能；编译、解释有别；Java/VB 不是典型 4GL 通则 |
| p.51 操作系统分类 | DOS 直接归为实时系统 | 传统 DOS 是单用户单任务；分类维度需区分 |
| p.53 病毒与宏 | “任何病毒都一定可清除”等绝对化 | 检测、清除、恢复均有能力边界；宏格式有版本差异 |
| p.54 速率，原页核对 | 千兆以太网写为约 1000000bit/s | 正确为 1000000000bit/s |
| p.54 IPv6，原页核对 | 写为 64 位 | 正确 128 位，与 p.171 正确表述一致 |
| p.67 开始菜单 | 右键单击打开开始菜单 | 左键、Win 或 Ctrl+Esc；右键是快捷菜单 |
| p.69—70 窗口说明 | 把右上角与左上控制图标、菜单混写 | 右上关闭按钮；传统左上控制图标双击可关闭 |
| p.75 只读属性 | 文件与文件夹只读功能过度概括 | 只读不等于不可删除；文件夹属性另有用途 |
| p.93 公式编辑 | 似乎必须依赖公式 3.0 | Word 2010 有内置“插入→公式” |
| p.112 错误值表，原页核对 | 缺参数写 #N/A，#NAME 写成感叹号形式 | #N/A 为值不可用；名称错误写 #NAME? |
| p.117 Excel 表数题 | 暗示工作簿最多 255 张表 | 2010 主要受可用内存限制 |
| p.132、135—136 | 把隐藏／设置放映放到“幻灯片切换” | 正确功能区主要是“幻灯片放映”；换页效果才在“切换” |
| p.138—143 旧 PPT 功能题 | 内容提示向导、网页导出、旧菜单与 2010 混用 | 先判断版本，保留原理，不硬套路径 |
| p.148 网络组成 | “一个网络至少有一个专用服务器”式概括 | 对等网不要求专用服务器 |
| p.151、164 以太网拓扑 | 不区分传统共享与现代交换 | 区分物理和逻辑拓扑 |
| p.155 自动获取 IP | 认为每次一定不同 | DHCP 可续租同地址，也可分配不同地址 |
| p.156 填空答案 | HTTP 名称误写文件传输协议 | HTTP 超文本传输；FTP 文件传输 |
| p.167 主机范围 | /24 中末字节允许 255 | 常规主机 1—254；255 为广播 |
| p.174 域名题 | 单选只承认“一个 IP 多域名” | “一个域名多 IP”也可成立，p.183 有更完整选项 |
| p.186 邮件客户端 | Office 2010 中称 Outlook Express 2010 | 应区分 Outlook 2010 与旧 Outlook Express |
| p.190 分辨率 | 像素尺寸、PPI、DPI 混用 | 分别表示像素数量、像素密度、输出点密度 |
| p.193 压缩 | 把 PCM、预测等一概列有损压缩 | 看是否量化损失与是否压缩，不能只按名称判断 |
| p.199 外键 | 外键必须不是本表键 | 外键可同时属于本表主键，也可自参照 |
| p.211 NOT IN 例 | 用“非 C1/C2 的选课行”代替“未选 C1/C2 的学生” | 行条件与实体层面的不存在条件不同 |
| p.215—216 聚合 | COUNT 一般须 DISTINCT、HAVING 必须 GROUP BY | 按计数语义选择；HAVING 的语法范围依实现 |
| p.219—221 视图 | 将 DISTINCT、聚合查询等限制扩大为普遍规则 | 查询能力与可更新性不同；视图不自动补筛选字段 |
| p.4 目录与卷末 | 第三套起页列为 241 | 实际 p.241 仍为第二套选做题；第三套标题在 p.242 |

**如何处理疑题**：先核对原页，排除 OCR；再看版本、单位、条件；若题干选项仍无法构成唯一正确答案，标为疑题，以知识规则复习，不强行制造一个“标准答案”。本书部分卷面分值标注也有不一致，不据此推定真实考试各部分分值。
