## 内容标识

- **正文知识**：讲义主体涉及的概念、操作和方法，按学习逻辑重新表达；明显错误按正确规则修订。
- **题目／题源补充**：题目已要求，但正文未系统解释、仅一笔带过或缺少必要操作步骤的内容，并标注相关页码。
- **延伸**：根据现有题型推演的相邻知识，不代表已在原书出现，也不保证实际考试一定涉及。
- **纠错／版本说明**：原书错误、答案疑点、单位口径或 Windows／Office 不同版本造成的差异。主要问题汇总在[附录 D](/posts/computer-review/12-corrections/)。

文中 **p. 或“第×页”均指原 PDF 页码，不是本整理稿页码**。通过系列目录可直接跳转到各篇文章。未逐字抄录重复题干，重点保留考点及推理；并非全书逐题答案册。

## 怎样使用

1. 每章先读正文，理解术语、对照表和例题，不只背结论。
2. 完成对应原书习题，按“错误在概念／操作／计算／题目本身”分类记录。
3. 用[附录 C](/posts/computer-review/11-exam-checklist/)对照题目倒查遗漏；程序设计和 SQL 综合能力分别补读[附录 A](/posts/computer-review/09-programming/)、[附录 B](/posts/computer-review/10-database-exercises/)。
4. 做计算前确认单位和版本。对原书与常识冲突处查看[附录 D](/posts/computer-review/12-corrections/)；考前用[附录 E](/posts/computer-review/13-quick-reference/)快速自检。

本资料沿用讲义的 Windows 7、Office 2010 背景；涉及 Windows 2003/XP、旧网络与旧产品时明确其历史语境。原书首页印有“2027 年”考纲字样，这里仅反映文件内容，未把培训讲义中的该标题当作已核验的官方发布文件。

## 原资料的校验记录

以下为原资料随附记录的摘录，说明原整理稿的检查范围，不代表对每道习题均验证了唯一答案。

### 可执行与数值校验

- 降序插入示例：遍历 0—40 全部 41 个输入，结果保持排序、长度和元素集合正确。
- 冒泡排序示例：空数组、单元素、正序、逆序、负数和重复值均通过。
- 三数最大值、1—100 累加与六行字母金字塔均通过结果检查。
- 学生／课程 SQL：建表主外键、三表连接、NOT EXISTS（含未选课者）及 NULL 聚合行为已用 SQLite 内存数据验证。
- 试卷 1 五组职工 SQL：筛选、三表连接、平均工资、跨公司加薪、先子后父删除通过。
- 试卷 2 插入与更新示例：NULL、身份证文本、日期和主键定位通过。
- 社团综合题：双社团参加者去重、0 人社团、并列最高人数均通过。
- 补码、点阵、音频容量与 /26 子网结果通过数值检查。

### 校验边界

- SQL 使用本地 SQLite 内存数据库验证兼容的建表、查询与更新逻辑；MySQL 类型、GRANT/REVOKE、WITH CHECK OPTION 等方言或权限功能未据此宣称跨库实测。
- 未对 Windows 7、Office 2010 每个界面命令进行实机自动化操作；版本相关疑点保留限定和说明。
