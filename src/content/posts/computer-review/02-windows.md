## 2.1 版本、桌面、图标与任务栏

- Windows 7 常见版本：Starter 初级版、Home Basic 家庭普通版、Home Premium 家庭高级版、Professional 专业版、Enterprise 企业版、Ultimate 旗舰版。
- 桌面是登录后看到的工作区域，相关文件存于桌面文件夹；实际桌面可能组合个人桌面和公用桌面内容，路径不固定为 Administrator 用户目录。
- 系统图标、文件图标、文件夹图标、快捷方式图标要能识别。普通快捷方式扩展名 `.lnk`，默认常有左下角小箭头。
- 快捷方式是指向对象的链接；**删除快捷方式通常不删除原对象**。可为程序、文档、文件夹等建立快捷方式。
- 右击桌面可设置屏幕分辨率、个性化、背景、屏幕保护、小工具等；不能通过此操作更换显示器硬件型号。
- 任务栏显示开始按钮、程序按钮、通知区域、显示桌面等；可移动到屏幕四边、调整大小、自动隐藏或锁定。Windows 7 的固定程序按钮与传统“快速启动”并不完全相同。
- Aero Peek 预览桌面；Aero Snap 拖到屏幕边缘平铺或最大化；Win+Tab 为支持 Aero 时的 Flip 3D。
- **左键单击开始按钮、Win 键、Ctrl+Esc 可打开开始菜单**；右击是快捷菜单，教材第 67 页“右键打开开始菜单”不准确。

## 2.2 窗口、对话框与菜单

- 窗口常见组成：标题栏、菜单／工具栏、地址栏、搜索栏、导航窗格、工作区、滚动条、状态栏／细节窗格。
- 拖标题栏移动窗口；拖边框调整可调整窗口大小；双击标题栏常用于最大化与还原。最大化、最小化、关闭是不同操作。
- **最小化不等于关闭，也不等于暂停程序**；多窗口可同时存在，通常只有一个前台活动窗口接收键盘输入。
- 对话框用于设置或确认，常有按钮、文本框、列表框、选项卡、复选框、单选按钮；教材所称“不能改变大小、没有最大化”是传统典型样式，不能扩大成全部程序的绝对规则。
- 复选框：允许多选；单选按钮：同组通常只能选一项；确定执行并关闭、取消放弃本次设置、应用保存设置而不关闭。
- Tab/Shift+Tab 在控件间切换；Ctrl+Tab/Ctrl+Shift+Tab 通常切换选项卡。
- 灰色菜单项：当前不可用；省略号 `…`：通常还需后续输入或对话框；右箭头：子菜单；勾选标志：该功能已启用。
- Alt 或 Alt+相应字母可访问菜单；执行“编辑→复制”的传统键序可以是 Alt+E，再按 C。

## 2.3 文件、文件夹、路径与库

- 文件是按名称保存的相关数据集合；文件夹组织文件与子文件夹；目录呈树形。根目录是某驱动器目录树的起点。
- 文件名常写“主名.扩展名”，扩展名表示文件类型及默认关联；可以没有扩展名，也可有多个点，通常以最后一个点后的部分为扩展名。
- Windows 常见文件名最大长度为 255 个字符，**不等于整个路径一定允许任意长度**。
- 文件名不能含九个字符：`\ / : * ? " < > |`；允许汉字、空格等。普通 Windows 文件系统使用中名称通常不区分大小写。
- 同一文件夹不能有完全同名的两个对象；不同目录可以同名。`报告.docx` 与 `报告.txt` 的完整名称不同。
- 绝对路径从驱动器／根位置开始，如 `D:\资料\练习.txt`；相对路径从当前工作目录出发，如 `资料\练习.txt`。
- **库**是对多个位置的文件夹进行统一组织与访问，包含到库中不会把原文件搬走。默认文档、音乐、图片、视频库。
- 查找通配符：`*` 代表任意长度字符，`?` 代表一个字符；如 `*.txt` 查文本文件。Windows 搜索的实际匹配还受索引、扩展名规则影响，基础题按简化规则理解。
- 扩展名与文件内容不同：仅改后缀不会完成格式转换；文件关联记录于系统配置／注册表。【题源：第 240 页第 70 题】

## 2.4 文件基本操作

| 操作 | 方法／结果 |
|---|---|
| 选连续多个 | 单击首项，再 Shift+单击末项 |
| 选不连续多个 | Ctrl+逐个单击 |
| 全选 | Ctrl+A |
| 重命名 | F2、右键菜单，或选中后再单击名称 |
| 复制 | Ctrl+C，再 Ctrl+V |
| 移动 | Ctrl+X，再 Ctrl+V |
| 同分区直接拖动 | 默认移动普通文件 |
| 跨分区直接拖动 | 默认复制普通文件 |
| 强制复制／移动 | Ctrl+拖动／Shift+拖动 |
| 撤销 | Ctrl+Z；并非所有操作均可撤销 |
| 属性 | 右键“属性”或 Alt+Enter |

查看方式：超大、大、中、小图标、列表、详细信息、平铺、内容；详细信息可看到名称、日期、类型、大小等。排序可按名称、大小、类型、修改日期等。

文件属性：只读、隐藏、系统、存档。只读不是“无法删除”；隐藏不是加密；文件夹只读属性的实际用途与普通文件不同，不能一概认为设置后文件夹内所有内容都不可修改。

## 2.5 剪贴板与回收站

| 比较 | 剪贴板 | 回收站 |
|---|---|---|
| 主要位置 | 内存 | 磁盘 |
| 用途 | 剪切、复制、粘贴的数据中转 | 暂存可恢复的已删除文件 |
| 关机后 | 传统 Windows 7 剪贴板内容通常丢失 | 文件通常仍保留 |
| 容易混淆 | 粘贴不会自动清空剪贴板 | 删除不等于立即释放到完全不可恢复 |

- Windows 7 普通剪贴板保留最新一次剪切／复制的数据；Office 自有剪贴板可保存多条，不能混为一谈。
- Print Screen 复制全屏图像；Alt+Print Screen 复制当前活动窗口图像；仅按此键通常不会自动保存为磁盘文件。
- 本地磁盘 Delete 通常进入回收站；Shift+Delete 绕过；U 盘、网络位置或超出限制等情境可能直接删除，以系统提示为准。
- 可还原到原位置，也可清空；回收站大小、直接删除选项可设置。空回收站与非空回收站图标不同。
- 复制图文到记事本只保留可表示的纯文本，图片和复杂格式不能保留。

## 2.6 控制面板、附件、账户与维护

- 程序和功能：卸载／更改已安装软件；设备管理器：查看硬件、安装更新驱动、启用禁用设备；删除桌面快捷方式不等于卸载软件。
- 即插即用表示可自动识别、配置设备，**不表示无需驱动**；驱动可能已由系统提供。
- 鼠标可设置双击速度、主次键、指针、移动速度等；“单击速度”不是常见设置项目。键盘可设置重复延迟、重复速度、光标闪烁速度。【题源：第 229 页】
- 可安装多台打印机，通常选定一台默认打印机；“默认”不等于“唯一可用”。
- Administrator 是管理员账户，Guest 是来宾账户；管理员仍受权限机制与系统保护约束，不能把“权限高”理解成无需任何限制。
- 记事本 `.txt`：纯文本；写字板：支持一定格式；画图：Windows 7 常默认 PNG；录音机常用 WMA；计算器有标准、科学、程序员、统计模式。
- IE 为浏览器，Windows Media Player 为媒体播放器；它们与 Office 的 Word、Excel 不是同一类组件。
- 启动文件夹可放程序快捷方式实现登录时运行；命令提示符提供命令行环境，**不等于机器切换成独立 DOS 系统**。
- 关机、重新启动、注销、切换用户、锁定、睡眠、休眠要区分：睡眠主要保留内存并保持供电，休眠把状态保存到磁盘；锁定保留当前会话，注销结束用户会话。
- **磁盘清理**删除可清理的临时文件；**碎片整理**改善机械磁盘中文件的连续性；**磁盘检查**检查文件系统／磁盘问题。三者功能不同，不把传统机械硬盘碎片整理直接套到 SSD。
- **虚拟内存【题目补充】**：借助磁盘分页文件等扩展可用虚拟地址空间；内存紧张可能导致频繁换页、磁盘读写和性能下降。第 225 页第 9 题据此判断内存不足，但现实中频繁读盘也可能有其他原因。

## 2.7 Windows 7 快捷键速查

| 按键 | 功能 |
|---|---|
| Win／Ctrl+Esc | 开始菜单 |
| Win+E／Win+R | 资源管理器／运行 |
| Win+D／Win+M | 显示桌面切换／最小化窗口 |
| Alt+Tab／Alt+Esc | 选择切换窗口／依次切换窗口 |
| Win+Tab | Aero 环境下 Flip 3D |
| Alt+F4 | 关闭当前应用窗口 |
| Ctrl+Shift+Esc | 直接打开任务管理器 |
| Ctrl+Alt+Delete | 打开安全选项界面，再选择任务管理器等 |
| Alt+Space | 活动窗口控制菜单 |
| F1／F2／F5 | 帮助／重命名／刷新 |
| Ctrl+Space | 传统输入法环境中切换中英文输入状态 |
| Ctrl+Shift | 传统默认配置下切换输入法 |
| Shift+Space | 全角／半角 |
| Ctrl+. | 部分中文输入法中切换中英文标点 |

输入法快捷键可能被用户或输入法软件重设。考试按题目指定的默认环境作答。
