## E.1 计算公式总表

| 题型 | 公式／规则 |
|---|---|
| r 进制转十进制 | 各位数码×r 的相应幂，再相加 |
| n 位无符号最大值 | 2^n−1 |
| n 位补码范围 | −2^(n−1) 到 2^(n−1)−1 |
| 负数补码转真值 | 无符号值−2^n |
| 存储换算 | 1B=8bit；本书通常 KB/MB 逐级 1024 |
| 按字节编址容量 | 2^地址位数 B；首末地址法末−首+1 |
| 单色点阵字模 | 字数×行点数×列点数÷8 B |
| 图像／基础显存 | 宽×高×位深÷8 B |
| 未压缩音频 | 采样率×位深×声道×秒÷8 B |
| 未压缩视频 | 每帧字节数×帧率×秒，音轨另加 |
| 理想传输时间 | 数据量 bit÷速率 bit/s |
| 子网可用主机 | 常规子网 2^主机位数−2 |
| 网络地址 | IP 与掩码按位 AND |
| Excel 区域格数 | (末行−首行+1)×(末列−首列+1) |
| 笛卡尔积 | 行数相乘、列数相加 |
| 自然连接列数 | 两表列数之和−同名连接列数 |

| 操作 | 快捷键与环境 |

| 帮助／重命名／刷新 | Windows 常用 F1/F2/F5 |

| 查找／替换 | Office Ctrl+F／Ctrl+H |

## E.3 逐章完成标准

| 章节 | 达到“会做题”的标准 |
|---|---|
| 1 基础 | 独立算进制、原反补码、ASCII、点阵和地址容量；辨硬件软件 |
| 2 Windows | 区分文件操作、窗口状态、内存与磁盘区域，掌握键鼠组合 |
| 3 Word | 由任务确定格式级别、视图、分隔符、表格及图文对象操作 |
| 4 Excel | 能手推引用变化、函数结果、筛选条件和汇总规则 |
| 5 PPT | 分清主题版式母版、动画切换，完成放映和打印设置 |
| 6 网络 | 能对应协议层、设备与地址，计算子网和传输时间 |
| 7 多媒体 | 能算音频图像视频容量，区分格式、压缩与安全概念 |
| 8 数据库 | 能画简单 E-R、定主外键、推关系运算、写 SQL 查询更新 |
| 程序设计补充 | 不用现成排序替代指定算法，写出插入、冒泡、判断、累加和图案循环 |

建议复习顺序：先按章节理解并做本章题，再集中练计算与 SQL／编程，最后使用“题源补充清单”和“纠错表”查缺补漏。卷末提供数据库或程序设计选做，但公共基础中的程序与数据库概念仍应掌握。
