## 4.1 工作簿、工作表与单元格

- Excel 为电子表格应用软件；**工作簿是文件，工作表是文件内的表，单元格是工作表基本单位**。
- 默认文件 `.xlsx`，旧格式 `.xls`；模板 `.xltx`，启用宏 `.xlsm`。
- Excel 2010 默认新建“工作簿1”，通常包含 Sheet1、Sheet2、Sheet3 三张工作表，数量可改；**工作簿的工作表上限主要受内存限制，不是固定 255 张**。
- 每工作表最多 **1048576 行、16384 列**；末列 XFD。Excel 2003 的 65536 行、256 列不能套到 2010 原生格式。
- A1 引用中列用字母、行用数字，如 C5 是第 3 列第 5 行；单元格区域用冒号，如 B3:E5。
- 区域单元格数 = `(末行−首行+1)×(末列序号−首列序号+1)`。B3:E5 为 3×4=12 个；D2:E4 为 3×2=6 个。
- 一个选区可以含很多单元格，但通常只有一个活动单元格。名称框显示地址／名称，编辑栏显示原始内容或公式，单元格通常显示结果。

## 4.2 工作表与窗口管理

- 单击标签选一张；Shift 选连续多张；Ctrl 选不连续多张；成组后在相同位置的输入可作用于组内全部表，完成后及时取消组合。
- 重命名：双击标签、右键、开始→格式；仅单击标签并直接打字不是标准重命名操作。
- 拖标签移动；Ctrl+拖标签复制；“移动或复制工作表”可跨工作簿操作。
- 工作表名称最长 31 个字符，不能包含 `: \ / ? * [ ]` 等，不能与同工作簿已有表同名。【延伸】
- 可插入、隐藏、取消隐藏、删除工作表；一个普通工作簿至少保留一张可见工作表；删除工作表通常无法用普通 Ctrl+Z 恢复。
- 拆分窗口可形成 2 或 4 个窗格；冻结窗格固定标题行／列，滚动时仍可见。**冻结不是锁定内容不许编辑**。
- 冻结所选单元格上方所有行与左侧所有列；如选 B2 冻结，可固定第 1 行和 A 列。
- Ctrl+Page Up/Down 切换工作表；Ctrl+Home 回到 A1；Ctrl+End 到已使用区域末端。

## 4.3 数据输入、编辑、显示与填充

- 文本默认左对齐，数值与日期时间默认右对齐；手动格式能改变对齐，所以不能只凭对齐判断真实类型。
- 纯数字常被识别为数值；`'00123` 或先设文本格式可保留前导零。电话号码、身份证号、学号通常宜作为文本。
- Excel 数值精度通常为 **15 位有效数字**；18 位身份证若已按数值输入损失精度，事后改为文本不能还原丢失位。
- 日期通常内部存为序列值，时间为一天的小数部分；日期时间输入受区域格式影响。输入 `1/2` 常被理解为日期；输入分数可用 `0 1/2`，或用 `=1/2` 得 0.5。
- Ctrl+; 输入当前日期，Ctrl+Shift+; 输入当前时间，为静态值；`=TODAY()`、`=NOW()` 为随重新计算更新的函数。
- 超过 24 小时的累计时长应用 `[h]:mm:ss` 等格式显示，不能简单使用普通时刻格式。
- F2、双击单元格或编辑栏可修改原内容；选中后直接输入通常覆盖原内容；Alt+Enter 在单元格内换行。
- Enter 确认，Esc 取消本次输入；编辑栏的“×”是取消当前输入，不是删除整个单元格。
- `1.234E+05` = 123400；百分比 `30%` 的底层数值是 0.3；显示两位小数通常只改变显示，不改变底层数值。
- **清除内容**保留单元格及格式；**清除格式**保留内容；**删除单元格**使后续单元格移动。
- 插入单元格可右移、下移；删除单元格可左移、上移；整行通常在上方插入、整列在左侧插入。
- 填充柄位于选区右下角，指针为细黑十字；直接拖单个普通数值默认复制；Ctrl+拖通常切换为序列填充；选两个数可延伸等差数列；日期、星期、月份、文本数字组合可按序列填充。
- 自定义序列不是任何文字都自动认识；“甲乙丙丁”“一班二班”等须看内置或自定义规则，不能一概认定可自动递增。

## 4.4 公式、运算符及计算顺序

- 规范输入以 `=` 开头，公式可包括常量、单元格引用、运算符、函数。某些以 `+` 或 `-` 开头的输入也可被 Excel 接受，但考试规范写 `=`。
- 算术：`+ - * / ^ %`；比较：`= > < >= <= <>`；文本连接：`&`；引用：冒号表示区域、逗号表示联合、空格表示交集。
- 字符串放英文双引号内：`=B2&"成绩为"&C2`；不要用 `+` 代替字符串连接。
- 主要优先顺序：引用运算 → 一元负号 → 百分比 → 乘方 → 乘除 → 加减 → 文本连接 → 比较；同级通常从左到右，括号优先。
- Excel 的一元负号优先级要特别留意：`=-2^2` 按 Excel 规则得 4；要表达负的平方写 `=-(2^2)`。
- 常规状态单元格显示公式结果、编辑栏显示公式；“显示公式”模式会改变这一点。
- 默认自动重算；引用数据改变，相关结果自动更新；手动计算模式例外。

## 4.5 相对、绝对与混合引用

| 原引用 | 锁定内容 | 向右 2 列、向下 3 行复制后 |
|---|---|---|
| A1 | 不锁定 | C4 |
| `$A$1` | 列与行 | `$A$1` |
| `$A1` | 仅列 | `$A4` |
| `A$1` | 仅行 | `C$1` |

**解题步骤**：先算目标位置相对原位置移动多少行、列，再对每个引用逐项处理；有 `$` 的部分在复制中保持不变。F4 可循环切换引用类型。

典型题：

1. C1 中 `=$A1+B$2` 复制到 E4：右移 2 列、下移 3 行，结果 **`=$A4+D$2`**。
2. B3 中 `=C3+$D5` 复制到 D7：右移 2 列、下移 4 行，结果 **`=E7+$D9`**。
3. D6 中 `=$B$2+C6` 复制到 C7：左移 1 列、下移 1 行，结果 **`=$B$2+B7`**。
4. E5 中 `=SUM(E1:E4)` 复制到 B7：左移 3 列、下移 2 行，变为 **`=SUM(B3:B6)`**。
5. D7 中 `=A7+$B$4`，在第 3 行前插入整行：公式所在位置变 D8，公式变 **`=A8+$B$5`**。

**绝对引用只保证复制时相应部分不变，不保证插入／删除行列时永远不变。** 移动公式与复制公式也不同：普通剪切移动公式时，其引用通常保持对原目标的引用。

- 跨表：`=Sheet2!C5`；表名含空格或特殊字符时可写 `='销售 1'!C5`。
- 跨工作簿：`='[工作簿2.xlsx]Sheet1'!C5`；路径是否显示与被引用文件是否打开等有关。
- 命名区域可代替地址，通常默认引用绝对区域；把公式中的名称复制到下一行不一定变为下一行数据。【题源：第 128 页】

## 4.6 常用函数及易错点

| 函数 | 用途 | 例子 |
|---|---|---|
| SUM | 求和 | `=SUM(A1:A10)` |
| AVERAGE | 数值均值 | `=AVERAGE(A1:A10)` |
| MAX／MIN | 最大／最小 | `=MAX(A5:D20)` |
| COUNT | 数值项个数 | `=COUNT(A1:A10)` |
| COUNTA | 非空项个数 | `=COUNTA(A1:A10)` |
| COUNTBLANK | 空白项统计【延伸】 | `=COUNTBLANK(A1:A10)` |
| COUNTIF | 单条件计数 | `=COUNTIF(C2:C20,">=60")` |
| SUMIF | 单条件求和【延伸】 | `=SUMIF(B2:B20,"一班",C2:C20)` |
| IF | 条件判断【延伸】 | `=IF(C2>=60,"及格","不及格")` |
| RANK／RANK.EQ | 排名 | `=RANK(C2,$C$2:$C$20,0)` |
| ROUND | 按位四舍五入【延伸】 | `=ROUND(A1,2)` |

- AVERAGE 通常忽略引用区域里的文本和真正空单元格，但把数值 0 算入分母；**不能机械写成 SUM 除以区域格数**。
- A2 是文本“300”，A3=200，A4=500：`COUNT(A2:A4)=2`、`SUM(A2:A4)=700`、`AVERAGE(A2:A4)=350`、`COUNTA(A2:A4)=3`。
- 以上是“引用区域”规则，直接写在参数中的数字文本、逻辑值可能有不同处理方式，不要扩大结论。
- COUNTA 可把公式结果为空字符串 `""` 的单元格计为非空；肉眼看空不一定真正为空。
- `COUNT(7,8,8,9)=4`，COUNT 计数而不是求和。
- 多区域均值：`=AVERAGE(A3:B7,D3:E7)`；SUM(A1:A3,A8:A12) 是两个区域的联合，不是 A1:A12 全部。
- RANK 第三个参数 0 或省略为降序，非零为升序；并列名次可能使后续名次跳号。
- COUNTIF 中比较条件通常要加引号；把条件与单元格连接可写 `">="&E1`。

## 4.7 错误值

| 显示 | 常见原因 | 处理思路 |
|---|---|---|
| `#####` | 列宽不足；或负日期／时间不能按当前格式显示 | 调整列宽、检查格式和底层值 |
| `#DIV/0!` | 除数为零或按零处理的空值 | 检查分母 |
| `#VALUE!` | 参数／运算数据类型不适合 | 检查文本、日期和数字类型 |
| `#REF!` | 引用失效 | 检查删除行列或区域后的引用 |
| `#NAME?` | 函数、名称或文本写法不能识别 | 检查拼写、引号 |
| `#N/A` | 值不可用，常见于查找失败 | 检查查找条件与源数据 |
| `#NUM!` | 数值参数或计算范围不合法 | 检查参数和数值范围 |
| `#NULL!` | 指定的引用交集为空 | 检查引用运算符 |

**【纠错】原书把“缺少函数参数”直接归为 `#N/A` 不准确。** 参数不足常触发公式输入提示，不能用一个固定错误值概括。

## 4.8 排序、筛选、记录单和分类汇总

- 数据清单第一行为字段名，每行是一条记录，每列是一个字段；避免空表头、混合类型和随意合并单元格。
- 排序改变记录顺序；筛选隐藏不符合条件的记录，**不会把它们删除**。
- 多关键字排序先按主要关键字，相等时比较次关键字。Excel 2010 最多 64 个排序层级；不是旧版题中的“最多三个”。
- 默认通常从上到下按列排序，也可从左到右按行排序；可按值、单元格色、字体色、图标等排序。
- 排序应保持整条记录一起移动，不能只排序姓名列造成姓名与成绩错位。
- 自动筛选可按数值、文本、日期、颜色等；多个字段同时筛选通常为 AND；单个字段自定义可设置两个条件为与／或。
- 高级筛选要构造条件区：**同一行条件为 AND，不同行为 OR**。例如“计算机系且成绩≥80”放同一行；“计算机系或成绩≥80”分两行。
- 高级筛选可原地显示或复制结果，可选择不重复记录；条件标题要与对应字段匹配。
- 记录单便于逐记录增删改查，默认可能需添加按钮；公式计算字段在记录单中通常只显示结果，不直接编辑公式；`5/11` 表示当前第 5 条，共 11 条。
- **分类汇总先按分类字段排序**，再选分类字段、汇总方式、汇总项；默认常为求和，也可计数、平均、最大、最小、乘积等。
- 取消分类汇总用对话框“全部删除”，不是清空原数据；大纲级别用于切换总计、分组小计与明细。
- **【延伸】数据透视表**：按字段拖放汇总、交叉分析，原数据变化后通常需刷新；不是只能对数值求和。

## 4.9 格式、图表与打印

- Ctrl+1 打开单元格格式：数字、对齐、字体、边框、填充、保护。教材个别题的快捷键选项有缺漏，应记真实操作。
- 合并居中可能仅保留左上角数据；自动换行与扩大列宽不同；条件格式根据条件改变外观，通常不修改原值。
- 嵌入式图表在工作表中；图表工作表单独占一个工作表标签；F11 常创建图表工作表，Alt+F1 常创建嵌入式图表。
- 图表数据区可不连续；建立后能改类型、数据源、标题、图例、坐标轴、数据标签；源数据改变通常会更新图表。
- 柱形／条形图比较类别；折线图看趋势；饼图看单系列各部分占整体比例；散点图看两个数值变量关系，**散点图与普通折线图的横轴含义不同**。
- 视图常用普通、页面布局、分页预览；页面设置有页面、页边距、页眉／页脚、工作表等项目。
- 打印区域指定打印哪些单元格；打印标题使每页重复表头；打印网格线需设置，屏幕可见不代表自动打印。
- 可设纸张、方向、缩放、居中、打印顺序、水平／垂直分页符；Excel 没有 PowerPoint 意义上的“打印讲义”。
- 工作表背景图片通常只在屏幕显示，不打印；这与插入的图片对象不同。
